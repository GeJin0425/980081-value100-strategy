# 国证价值100(980081) · MA250策略仪表盘

国证价值100指数(980081)的MA250均值回归策略研究。数据来自国证指数官网，历史可回溯到2013年。

**策略摘要**：价格接近MA250时买入，远离MA250时卖出；空仓期配置511260十年国债ETF。2013年至今（2014年1月才出现首笔信号，2013年为MA250热身期）回测年化约+18.3%，最大回撤-15.4%，夏普1.38，63笔已平仓交易，胜率70%；同期无脑持有480081全收益年化约+16.7%（历史数据，不代表未来收益）。

**参数验证口径**：训练集2013-01-01至2021-12-31（年化约+19.0%），测试集2022-01-01至今（年化约+16.8%，最大回撤-8.8%，夏普1.52），参数按训练集选出、测试集样本外验证。

- 标的：国证价值100指数(980081)，即价值ETF易方达(159263)跟踪的指数
- 数据源：国证指数官网 `https://hq.cnindex.com.cn/`，日线自2013-01-04起
- 收益口径：信号看980081价格与MA250；持仓收益和买入持有基准用480081全收益（159263不分红，股息留在净值内再投资，480081是合理代理）
- 在线看板：https://gejin0425.github.io/980081-value100-strategy/
- 主图支持 全部 / YTD / 近1年 / 近3年 / 近5年 时间范围切换
- 空仓期配置511260十年国债ETF；511260成立前的空仓期为现金
- 每日北京时间15:40自动抓取行情、重新计算并发布（GitHub Actions）

## 回测口径

- **980081**：仅用于生成MA250/偏离度/买卖信号，使用国证官网日收盘点位。
- **480081**：持仓阶段收益与“无脑持有”基准使用国证价值100全收益指数，代表159263含股息再投资的真实回报。
- **511260**：使用前复权收盘价（`DIVIDENDS_511260` 分红列表），空仓期国债收益已含现金分红。
- **佣金**：万0.5（0.005%），单笔最低0.5元；ETF免征印花税。配置在 `pipeline/export.py` 的 `FEE_RATE` / `FEE_MIN`。
- **成交时点**：信号日收盘价成交（信号与成交同价，实盘存在滑点与执行时点差异）。
- **一手股数**：指数点位回测按 `lot_size=1`，不套用ETF的100股/手规则；如果改为实盘159263，请把 `export.py` 里的 `lot_size` 改回100。
- 2013年数据用于MA250热身，第一笔信号最早出现在2014年1月。
